# Image Prompt Templates

## 9-Element Formula

Every image prompt follows this structure:

```
[Character sheet prompt_prefix]
[Scene description from creative_direction]
[9-element fill-in]

Shot type: candid portrait, coffee shop moment, office desk shot
Subject: [from character sheet]
Appearance: natural skin with visible pores, micro-shadows around nose/jaw
Outfit: [from character sheet]
Pose/Action: mid-conversation, adjusting collar, glancing left while thinking
Environment: candid office, modern cafe, urban street — NOT studio
Lighting: soft daylight near window, natural shadows, tungsten warmth
Camera: 85mm portrait lens, shallow depth of field, film grain 1-2%
Realism: photorealistic, authentic, unposed, candid, professional but approachable

Negative: plastic skin, airbrushed, perfect symmetry, studio background,
thousand-yard stare, AI glow, beauty filter, waxy skin, overly smooth
```

## Facial Lock Phrases (ALWAYS append)

```
Maintain the exact facial proportions, bone structure, eye shape, nose shape,
jawline, and skin tone from the uploaded reference photo. Do not AI-alter it.
Keep the face from the reference image 100% unchanged. Only modify clothing
and background. Faithful photographic reproduction, not a reinterpretation.
```

## Texture Keywords (ALWAYS include)

```
natural skin texture with visible pores, pore-level detail, natural microtexture,
tiny blemishes, subtle redness, uneven pigmentation, peach fuzz softly catching light,
subsurface scattering, natural subtle oil sheen, no beauty filter, no airbrushing
```

## Uncanny Valley Avoidance (ALWAYS include)

```
2-5% facial asymmetry, slightly different eyebrow curvature, eyes not perfectly balanced,
nose with subtle tilt, off-camera gaze, glancing left while thinking, caught mid-expression,
not a frozen pose, natural bokeh, no edge glow
```

## Scene-Specific Templates

### Café / Restaurant
```
Setting: bustling café interior, warm ambient lighting, wooden tables, blurred background
Composition: subject off-center right, generous negative space left/bottom for text overlay
Mood: calm, confident, approachable — like a friend sharing advice over coffee
```

### Kitchen / Work
```
Setting: professional kitchen, natural light from window, ingredients on counter
Composition: subject in action, mid-gesture, space for text on sides
Mood: hands-on, authentic, in the thick of it — not posed
```

### Pharmacy / Business
```
Setting: pharmacy counter, professional environment, clean lines
Composition: subject standing, thoughtful pose, text space above/below
Mood: reflective, serious, knowledgeable — "I've been here"
```

### Outdoor / Street
```
Setting: Playa del Carmen street, tropical light, colonial architecture blurred
Composition: subject walking or standing, full body or 3/4 shot, text overlay on sky/buildings
Mood: local, authentic, rooted in place — this is home
```
