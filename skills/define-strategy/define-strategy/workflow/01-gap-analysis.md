# Step 1 — Gap Analysis

Analyze the gap between current state and the vision's desired state.

- Current state assessment: what exists now?
- Competitor research: what are others doing? What can we learn?
- Internal analytics: what do our own metrics say?
- Desired state: from the S4 vision's selected option

**Output:** Gap analysis table (domain, current, desired, gap, priority).

**AI Review Gate:** Dispatch a fresh task sub-agent. Check: is the gap analysis complete? Does it cover all relevant domains? Are competitor insights incorporated?

**Commit:** Push the gap analysis to `management/change (S3)/<name>-strategy.md` (draft).
