# Step 3 — Initiative Generation

From the Horizons, generate the list of initiatives needed. Two types:

- **One-off Actions:** deliverables with clear endpoints (build a thing, complete research, launch a workstream)
- **Ongoing Actions:** recurring work (maintenance, monitoring, continuous improvement)

Each initiative: description, type (one-off/ongoing), horizon (H1/H2/H3), estimated effort.

**Ponytail check:** For each initiative ask — does this need to exist at all? What's the one-line version? Can an existing process absorb this?

**AI Review Gate:** Dispatch reviewer. Check: are all gaps covered? Are initiatives specific enough? Are there initiatives that are speculative ("nice to have") rather than necessary?

**Human Review Gate:** Present initiatives. Human may add, remove, or reorder.

**Commit:** Update strategy doc with initiative list.
