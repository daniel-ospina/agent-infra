# Step 5 — Workflows Plan

For each gap in Step 4, decide the resolution. Follow this strict priority order:

1. **Delegate** — assign the initiative to an existing role. Default choice.
2. **Add skills/workflows** — if the role can absorb the work but needs new capabilities.
3. **Expand agreement** — if the initiative logically belongs to a role but the role's current boundaries don't cover it.
4. **Add role** — LAST RESORT. Only if: (a) recurring work scope exists, (b) no existing role can absorb it without overload, (c) distinct skillset or trigger pattern justifies it, (d) the initiative itself is logical and necessary. See `agent-roles.md` for full creation criteria.

**Default is delegation.** Every new role adds coordination overhead (S2). Question whether the work justifies the overhead.

**AI Review Gate:** Check: were all other options exhausted before adding a role? Do new roles meet the creation criteria?

**Human Review Gate:** Human approves role changes.

**Commit:** Update strategy doc with workflows plan.
