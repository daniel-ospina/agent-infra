# Table Slide Template

**Usage:** Data comparisons, feature matrices, pricing tiers, timelines.

**Markdown:**
```
# [TABLE TITLE]

| [Col 1] | [Col 2] | [Col 3] | [Col 4] |
|---------|---------|---------|---------|
| [R1C1] | [R1C2] | [R1C3] | [R1C4] |
| [R2C1] | [R2C2] | [R2C3] | [R2C4] |
| [R3C1] | [R3C2] | [R3C3] | [R3C4] |
```

**Brand application:**
- Heading: Outfit 32pt, purple (#5B3B8C)
- Header row: white (#FFFFFF) text on purple (#5B3B8C) background
- Data rows: Inter 20pt, alternating cream (#EFE9DC) / white (#FFFFFF)
- Borders: muted (#C9BBE0), 1px
- Highlight column: yellow (#F2C94C) background for emphasis

**Example:**
```
# Crecimiento por Ciudad

| Ciudad | Partners | Usuarios | Crecimiento |
|--------|----------|----------|-------------|
| Playa del Carmen | 180 | 5,200 | +28% |
| Tulum | 95 | 2,800 | +42% |
| Cancún | 120 | 3,100 | +18% |
| **Total** | **395** | **11,100** | **+25%** |
```

**⚠️ Max 5 columns, 8 rows.** Larger tables → split or use appendix.
