# Two-Column Slide Template

**Usage:** Comparisons, text+image, before/after, pros/cons, dual perspectives.

**Markdown (text + text):**
```
# [HEADING]

## [Left Column Title]
- [Point 1]
- [Point 2]
- [Point 3]

|||

## [Right Column Title]
- [Point 1]
- [Point 2]
- [Point 3]
```

**Markdown (text + image):**
```
# [HEADING]

## [Text Section Title]
[Paragraph text or bullet points]

|||

![Image description](https://res.cloudinary.com/eldato/image/upload/...)
```

**Brand application:**
- Heading: Outfit 32pt, purple (#5B3B8C), full-width
- Column titles: Outfit 24pt, deep purple (#3F2766)
- Text: Inter 20pt, deep purple (#3F2766)
- Divider: vertical muted (#C9BBE0) line between columns
- Background: cream (#EFE9DC)
- Image column: image fills column width, maintains aspect ratio

**⚠️ Equal visual weight.** Both columns should have similar content density.
**⚠️ Max 3 bullets per column.** More → use separate bullet slides or a table.
