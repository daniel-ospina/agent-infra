# Bullet Slide Template

**Usage:** Lists, feature overviews, key points. 3-5 bullets per slide.

**Markdown:**
```
# [SECTION HEADING]

- **[Key Point 1]:** Supporting detail or context
- **[Key Point 2]:** Supporting detail or context
- **[Key Point 3]:** Supporting detail or context
- **[Key Point 4]:** Supporting detail or context
```

**Brand application:**
- Heading: Outfit 32pt, purple (#5B3B8C)
- Bullet text: Inter 24pt, deep purple (#3F2766)
- Bullet icons: yellow (#F2C94C) accent dots
- Background: cream (#EFE9DC)

**Variation (icon bullets):**
```
# 📊 Métricas Clave

- 🚀 **Crecimiento:** +35% YoY en revenue
- 👥 **Usuarios:** 12,000 activos mensuales
- 🏪 **Negocios:** 450+ partners activos
- 📱 **App:** 4.8★ rating en App Store
```

**⚠️ Max 5 bullets.** More than 5 → split into two slides.
