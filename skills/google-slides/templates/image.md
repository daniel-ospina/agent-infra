# Image Slide Template

**Usage:** Full-bleed images, product shots, location photos, concept visuals.

**Markdown:**
```
# [IMAGE TITLE / LABEL]

![Alt text describing the image](https://res.cloudinary.com/eldato/image/upload/...)

[Optional caption or context line]
```

**Brand application:**
- Title/label: Outfit 24pt, white (#FFFFFF) with dark overlay on image
- Caption: Inter 16pt, muted (#C9BBE0)
- Image: full-bleed (edge to edge) or centered with 80px margins
- Overlay: gradient from deep purple (#3F2766) at bottom (0-30% height, 50% opacity) for text readability

**Image requirements:**
- Public URL (Cloudinary, no auth-required URLs)
- PNG or JPEG, <50MB
- Minimum resolution: 1600x900 (matches 16:9 LARGE thumbnail)
- No text in image — text belongs in slide layout, not the image

**Variation (side image):**
Use two-column template instead — image on one side, text on other.

**⚠️ One image per slide.** Multiple images → use two-column or split into multiple image slides.
