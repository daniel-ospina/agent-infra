# Slide Structures (Carousel Templates)

## 3-Pilares (9-10 slides)

```
1. Portada (photo-hero)      — Hook + promise
2. La Trampa (text-slide)    — The cost: $ spent vs real results
3. Historia A (photo-top)    — Personal credibility story
4. Historia B (photo-top)    — Second experience
5. El Insight (text-slide)   — The framework + niche declaration
6. Pilar 1 (text-slide)      — Ventaja
7. Pilar 2 (text-slide)      — Distribución
8. Pilar 3 (text-slide)      — Medición
9. Veredicto (text-slide)    — Why the current approach fails
10. CTA (cta)                — Autodiagnóstico + link
```

## 5-Tips (8-10 slides)

```
1. Portada (photo-hero)      — Hook + "5 cosas que..."
2. Contexto (text-slide)     — Why this matters
3. Tip 1 (photo-top/text)    — Concrete, actionable
4. Tip 2 (photo-top/text)    — Concrete, actionable
5. Tip 3 (photo-top/text)    — Concrete, actionable
6. Tip 4 (photo-top/text)    — Concrete, actionable
7. Tip 5 (photo-top/text)    — Concrete, actionable
8. Conclusión (text-slide)   — Tie together
9. CTA (cta)                 — Link
```

## Before-After (7-9 slides)

```
1. Portada (photo-hero)      — "De X a Y en Z tiempo"
2. El Problema (text-slide)  — What was broken
3. La Causa (text-slide)     — Why it was broken
4. El Cambio (photo-top)     — What changed
5. La Solución (text-slide)  — The framework/method
6. El Resultado (photo-top)  — What happened after
7. Aprende (text-slide)      — Key lesson
8. CTA (cta)                 — "¿Quieres lo mismo?"
```

## Custom

Free-form. User defines slide count and types per slide. Orchestrator collects slide-by-slide direction during the brief discussion.
