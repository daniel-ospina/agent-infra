# UX Design Gate

> **Step 1.5** | → requires: `01-prerequisite-check.md` | → next: `02-research-intake.md` or `03-integration-surface.md`

## When to Run

Run when ALL of:
- Issue tier is Standard or Complex (not Micro)
- Plan touches UI files (`src/components/`, `src/pages/`, `src/app/`, `src/layouts/`)
- `UX_RATING ≥ medium` (from issue-scoping complexity ratings)

**Skip when:** Micro tier, pure backend/data/config changes, documentation-only, or `UX_RATING = low`.

## Process

1. **Read the UX design review skill** — `../../ux-design-review/SKILL.md`
2. **Scan proposed changes** — from the issue body and scoping plan, extract every change touching user-facing surfaces
3. **Classify against the 6-item checklist** — for each proposed change, check: metrics/labels, layout/hierarchy, copy/messaging, subscription gating, visual affordances, responsive behavior
4. **Present options** — for each matching checklist item, use `question-format` protocol: context, options (including "defer to planning"), recommendation with rationale
5. **Record decisions** — output a `### UX Design Decisions` table appended to the plan draft
6. **Proceed** — gate does not block. After decisions are recorded, continue to the next workflow step

## Skip Rules

Skip this gate entirely when:
- Plan touches zero UI files (determined from affected files list)
- All UX decisions were already made during `issue-scoping` Phase 3 (UX Prototype Gate) or `epic-workflow` UX Design Gate
- The issue is a pure refactor with no visible changes

## Output

Append to plan draft:

|---|---|---|---|
| <list per ux-design-review output> | | | |
