## Confirmed problem

Parent-side dispatch in BOTH tools (`extensions/builtin-tools/index.ts`
`spawnSubAgent`, `extensions/subagent/index.ts` `runSingleAgent`) has **no
bounded wait, no cut contract, and no identity-anchored orphan sweep** when a
child dies externally:

1. Both tools resolve on `proc.on("close")` only (builtin L1274, subagent
   L537); neither has an `exit` handler. A grandchild (MCP server / bash fork)
   holding the inherited pipes delays `close` indefinitely → the parent's
   await survives the child's death → unbounded block (the observed ~6h
   incident = orphan lifetime under account X, scope §2).
2. The subagent ext collapses an external signal-kill to `resolve(code ?? 0)`
   with no `stopReason` (L559/L562) → `isFailedResult` false → a cut is
   indistinguishable from SUCCESS.
3. The builtin heartbeat kill is a single-pid `proc.kill("SIGTERM")` (L1241)
   with a non-detached spawn (L1135–1139) — children-of-the-child survive the
   cut, hold the pipes, and a pgid sweep is unsafe by construction.
4. No wall-clock backstop on either parent await (`TASK_MAX_DISPATCH_MS`
   opt-in, default 0, L469–472; subagent `taskTimeout` is child-side only).
5. The wedged-alive class (markers stopped, process alive, tools in flight)
   is unbounded except by tool-stall at 6h — but once the marker stream is
   stale beyond the stateFresh window (max(2×T, 2×interval) = 60 min)
   tool-stall can NEVER fire (scope §2, F7).

## Chosen approach

### Task 1: Shared process-group sweep helper

**Intent:** One guarded, pgid-anchored sweep primitive both tools call on the
settle path (D2/D3) — TERM → 5s → KILL → verify-empty, with an exclusion
envelope that can never signal the orchestrator's own process group.

**Acceptance:**
- `extensions/shared/process-sweep.ts` (new) exports:
  - `getPgid(pid): number | null` — `ps -o pgid= -p <pid>` parse (macOS +
    Linux; Node exposes no `process.getpgid` — verified). Null on failure.
  - `killProcessGroup(pgid, signal)` — `process.kill(-pgid, signal)` with
    ESRCH swallow; `pgrep -g <pgid>` listing fallback.
  - `sweepProcessGroup(pgid, opts?: { signal?; timeoutMs?; detached?;
    disabled? }): Promise<{ ok: boolean; skipped?: string; survivors:
    number[] }>` — guard, then `pgrep -g` → SIGTERM → wait timeoutMs
    (default 5000) → SIGKILL → verify `pgrep -g` empty.
- **Runtime guard (round-2 F2, guardrail 2):** skip + `console.error` warn
  when `opts.detached === false` OR `opts.disabled === true` OR
  `pgid === getPgid(process.pid)` (the parent's own group). Never signals
  the orchestrator.
- **Safety-valve opt-out (scope D2):** callers pass `disabled: true` when
  their tool-level opt-out env is set — `TASK_SWEEP=0` (builtin) /
  `SUBAGENT_SWEEP=0` (subagent ext) — which disables the settle-path sweep
  ENTIRELY; `*_DETACHED=0` implies `*_SWEEP=0` (a non-detached spawn is
  always skipped + warned by the guard above, so the sweep opt-out is
  implied).
- **Verify-empty failure (F9d):** survivors after SIGKILL → `console.warn`
  log + resolve `{ ok: false, survivors }` — never throws, never blocks the
  settle. setsid-escape residual documented in the header comment: the
  argv-nonce `pgrep -f <marker>` pattern is the complementary catch.
- Header comment documents the #195 note (a killed mid-write worker can leave
  `index.lock`/partial worktree state → run the #195 worktree-recovery path
  before re-dispatching into that worktree).
- `pgid === child pid` by construction for a detached spawn (setsid → new
  session/group), but the helper verifies via `getPgid` where needed.

### Task 3: Builtin dispatch contract (spawnSubAgent wiring)

**Intent:** Wire the full contract into `spawnSubAgent` (L1116–1303):
exit-settle grace-race (F1), settle-exactly-once, cut taxonomy in a finalize
composition shared by the close path and the exit-settle fallback (D6),
detached spawn + pgid capture (D2), treeKill heartbeat kill (guardrail 2),
settle-path sweep hook (round-3 F2), stateFresh-false-gated backstop (D4),
`resolveUndefined = !hasOutput` on the exit-settle cut path (F10).

**Acceptance:**
- **Spawn** (L1135–1139) gains `detached: process.env.TASK_DETACHED !== "0"`
  (opt-out); capture `childPgid = detached ? getPgid(proc.pid) ?? proc.pid :
  null` at spawn.
- **Heartbeat kill** (L1241–1243) switches single-pid `proc.kill` →
  `treeKill(proc.pid, "SIGTERM")` with the 5s `treeKill(proc.pid, "SIGKILL")`
  escalation (mirror subagent killTree L470–484; precedent exit watchdog
  L306). Internal kills now close the pipes promptly; the sweep catches
  reparented survivors.
- **`classifyTaskExit(code, toolsInFlight)`** exported pure (taxonomy D6):
  `code === null` → `"cut"` (signal-death); `code !== 0` → `"failed"`
  (existing); `code === 0 && toolsInFlight > 0` → `"cut"` (frozen rule — clean
  mid-tool exit IS a cut, AC1's construction); else `"success"`.
- **Finalize composition shared by close + exit-settle** — one internal
  `finalize(code, settlePath)` runs `flushHeartbeatLineBuf(hbCtx)` (L1277
  behavior) then:
  - `"cut"` → compose cut result (headline "⚠️ Sub-agent was cut — process
    exited mid-tool / no life signs. Partial results below — parent should
    decide: accept, re-dispatch, or escalate." + aliveSummary + stderr/stdout
    tails, mirroring L1259–1272) with `details { model, provider, killed:
    true, reason: "cut", exitCode: code }`; `resolveUndefined = !hasOutput`
    (F10 + kill-clause contract: zero-partial cuts resolve `undefined` →
    retry wrapper re-spawns, L1246–1257 semantics) →
    `doResolve(undefined | composition, { sweep: true })`.

    `doResolve(..., { sweep: true })`.

    content + stderr→details) + `doResolve(..., { sweep: settlePath ===
    "exit" })` — **no-sweep ONLY for close-within-grace normal success;
    exit-settle success (live pipe-holder, AC12) MUST sweep** (round-3 F2).
- **Grace-race exit-settle (F1, guardrail 1):** `proc.on("exit", (code) =>
  ...)` — clearInterval(heartbeat), arm a 2s grace timer; on grace expiry →
  `finalize(code, "exit")`. The grace timer is CLEARED when `close` fires
  first (a stale timer can never re-fire into a recycled pgid). `close` within
  grace → the NORMAL path runs unchanged (plus the new taxonomy — F8/AC11).

  backstop, heartbeat kill, error. New `doResolve(value, opts?: { sweep?:
  boolean })`: on settle, if `opts.sweep && process.env.TASK_SWEEP !== "0" &&

  `sweepProcessGroup(childPgid, { detached })` (never blocks resolve — sweep
  latency does not count against the resolve indicator, F3); grace timer
  cleared; exitWatchdog disarmed. Settle + sweep run EXACTLY ONCE per
  dispatch. **Safety valve (scope D2):** `TASK_SWEEP=0` disables the
  settle-path sweep ENTIRELY (and `TASK_DETACHED=0` implies `TASK_SWEEP=0` —
  the shared guard skips + warns on a non-detached spawn).
- **Backstop (D4, guardrail 4):** `getTaskBackstopMs()` exported — env
  `TASK_BACKSTOP_MS`, default `DEFAULT_TOOL_STALL_MS + 1_800_000`

  ONLY when `stateFresh === false` (marker stream stale beyond the 60-min
  fresh window — healthy ticking agents exempt by construction; re-arm for
  another interval when stateFresh is true). On fire: clearInterval, treeKill
  SIGTERM, compose max-dispatch-style result with reason `"cut"` (headline
  mentions the backstop) + `resolveUndefined = !hasOutput` +
  `doResolve(..., { sweep: true })`. Source-drift-pinned (below).
- **"cut" headline** added to the heartbeat kill-composition headlines record
  (L1266 area).
- **Source-drift asserts** (builtin-tools.test.ts, pattern = armExitWatchdog
  assert L559–560): `settled` gates exit-settle/close/backstop; grace timer
  cleared on close; sweep wired on the settle-path basis (exit-settle OR
  abnormal-close; no-sweep only close-within-grace normal); backstop gated on
  `stateFresh === false`; `DEFAULT_TOOL_STALL_MS` literal 21_600_000
  unchanged; spawn has `detached:` with `TASK_DETACHED` opt-out; sweep gated
  on the `TASK_SWEEP=0` safety valve (settle-path sweep fully disabled when

## Runtime prerequisites / risks

- **pgrep / ps availability:** both macOS and Linux have `pgrep`; the helper
  keeps the tree-kill ps fallback pattern. Sweep commands run via execSync
  with a 2s bound (tree-kill precedent).
- **Fake-pi nonce authenticity:** the fake `pi` reads `$TASK_HEARTBEAT_NONCE`
  from its env — markers are authentic by construction (no forgery).
- **Detached spawn semantics (F9c):** Ctrl+C / terminal SIGINT no longer
  propagates to the child and job control no longer applies; the sweep is the
  cleanup path for interrupted dispatches. Documented in the spawn comment.
- **Stopped processes:** SIGTERM is queued while a SIGSTOP'd process is
  stopped; the 5s SIGKILL escalation reaps it (works on stopped processes).
  SIGSTOP-variant resolve bound ≈ 54.5s — keep the test assertion < 60s.
- **Recycled-pgid hazard:** closed by F1 (settle-exactly-once `settled` +
  `swept` flags; grace timer cleared when close fires; sweep on the exit-
  settle path only when close did NOT fire within grace — a live pipe-holder
  keeps the pgid alive there by construction).
- **Backstop calibration:** builtin fires only when `stateFresh === false`
  (detector-dead window); ext fires only on byte-staleness (weaker semantics,
  documented). Env opt-outs retained (`TASK_BACKSTOP_MS=0` /
  `SUBAGENT_BACKSTOP_MS=0`) for deliberate unbounded-wait configs.
- **Sweep safety valves (scope D2):** `TASK_SWEEP=0` / `SUBAGENT_SWEEP=0`
  disable the settle-path sweep entirely; `*_DETACHED=0` implies
  `*_SWEEP=0` (non-detached spawn → sweep skipped + warned by the shared
  guard — the parent's own pgid is never signaled).
- **Integration test runtime:** sleep-based variants add ~30–60s to the
  builtin integration suite (SIGSTOP ~20s, wave-of-3 ~30s, sweep poll ≤ 15s
  per dispatch). Acceptable at developer-gate only (not CI-gated).
- **Out of scope (do not touch):** `DEFAULT_TOOL_STALL_MS` (6h) — source-
  drift-pinned; the 300s first-message clause; `TASK_MAX_DISPATCH_MS` opt-in
  semantics; #195 worktree recovery (doc coupling only); the subagent ext
  marker/liveness emitter (ext bound = byte-freshness backstop + exit-settle).
